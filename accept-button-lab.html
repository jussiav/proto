Accept button — contrast lab

Temporary page. Candidates for the offer card / negotiation modal accept button, all drawn from the brand palette, all measured against WCAG 2.0 AA for normal text (4.5:1) — the button's label is 14px medium, so the 3:1 large-text allowance does not apply.

Every ratio below is computed by this page from the button's own rendered text colour and its background, so the numbers cannot drift from what is drawn. Hover any button and its hover state is re-measured.

Where we are

The accept green in production today. It fails too, which is the thing to know before reading the rest: this is not a regression to undo, it is a problem to solve.

Light fill, dark label

The main direction: keep a bright, cheerful green and let the label carry the contrast. Every one of these is a brand fill from either the green ramp or the design library's success ramp, with the label in a dark tone from the same family — or in black, navy or slate where that reads cleaner.

Deeper fill, white label

The other way round, for comparison. White text needs a considerably darker fill than anything above — the two at the end show where it stops working.

Text shadows, borders, glows and outlines do not change a WCAG contrast ratio. The ratio is computed from the text colour against the background directly behind it. A shadow can make text feel more legible on a photo; it does not make a failing button pass.

Nor does making the button bigger — at this size. The 3:1 large-text allowance starts at 18.66px bold or 24px regular. The card's label is 14px medium, so it needs the full 4.5:1.

Hover states need to pass too. Each candidate's hover is wired here; hover any of them and the ratio re-measures live.
