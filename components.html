CarCard

The seller's vehicle card. One definition shared by the funnel (contact, success) and the offers page (published listing + draft cards). Rendered vanilla — no build step — because a broken vue-tests build would break the funnel mid-user-test. Flips to photo-left via a container query at 480px of its own width, not a viewport breakpoint.

Narrow container — stacked (container < 480px)
