Design initiative · details step · VWO front-end test

Informed ad creation

One collapsed help panel on the ad funnel's details step that tells sellers what the ad will ask for, so they can prepare. Built as a front-end A/B test in VWO.

Status: ready to build · copy pending final approval October 2026

What to build

  • A VWO front-end test with two arms. Control: the page as it is. Variant: the panel below is injected. No backend, Vue or stylesheet changes.
  • One page, one step: the C2B ad funnel's first step, titled “Löysimme autosi tiedot!”, or “Täytä autosi tiedot” when the car's details were not found. Show the panel under both titles.
  • One element: a link that expands an inline panel, closed by default. It copies the photo tips (“Vinkkimme parhaisiin kuviin”) on the photos step: same classes and same animation, with an info icon instead of the camera and its own copy.
  • Nothing is stored and nothing else changes. No other step, field, validation or button is touched.
  • The build code below is the source of truth. Use it as written; the preview runs exactly that code.

Löysimme autosi tiedot!

Tarkista ja täydennä tarkemmat tiedot, jotta voimme valmistella ilmoituksesi autoliikkeille.

States

  • Closed (default, every visit): only the link shows, one line under the description.
  • Open: the panel folds out under the link and the step's content moves down. About 360px tall on desktop, 420px at 375px wide.
  • Closing: the link again, the ✕ or “Sulje”. ✕ and “Sulje” return keyboard focus to the link.

Compare with the photo tips on the live funnel's photos step: the panel must look and behave the same.

Where it goes

  • URL: autovex.fi/tarjouspyynto and autovex.fi/tarjouspyynto/<draft id>. Exclude /tarjouspyynto-b2b.
  • Step: the funnel is a single-page app, so the URL alone does not identify the step. The details step is the only one that renders img.equipment-info-image; inject only while it is in the DOM.
  • Insertion point: directly after the element that wraps h2[data-testid="page-title"] and the description, as its next sibling. data-testid="page-title" is on every step; the image check is what limits it to this one.
  • Timing: the step mounts after page load and can re-render. Watch the DOM and insert whenever the step is present and the panel is not; never insert twice.

  function mount() {
    if (document.getElementById(ID)) return;
    // Only the C2B details step renders this image.
    if (!document.querySelector('img.equipment-info-image')) return;
    var title = document.querySelector('h2[data-testid="page-title"]');
    if (!title || !title.parentElement) return;

    if (!document.getElementById(ID + '-style')) {
      var style = document.createElement('style');
      style.id = ID + '-style';
      style.textContent = CSS;
      document.head.appendChild(style);
    }
    // The title's wrapper holds the title and the description. Inserting after
    // it puts the panel in the step's own 24px gap.
    title.parentElement.insertAdjacentHTML('afterend', MARKUP);
    wire(document.getElementById(ID));
  }

  function wire(root) {
    var trigger = root.querySelector('#av-ad-prep-trigger');
    var panel = root.querySelector('#av-ad-prep-panel');
    var timer = null;

    function isOpen() { return trigger.getAttribute('aria-expanded') === 'true'; }

    function open() {
      clearTimeout(timer);
      panel.hidden = false;
      panel.classList.add('av-collapsed');
      void panel.offsetHeight; // paint the collapsed state before animating
      panel.classList.remove('av-collapsed');
      trigger.setAttribute('aria-expanded', 'true');
    }

    function close(returnFocus) {
      if (!isOpen()) return;
      panel.classList.add('av-collapsed');
      trigger.setAttribute('aria-expanded', 'false');
      timer = setTimeout(function () { panel.hidden = true; }, DURATION);
      if (returnFocus) trigger.focus();
    }

    trigger.addEventListener('click', function () { isOpen() ? close(false) : open(); });
    root.querySelectorAll('[data-av-close]').forEach(function (btn) {
      btn.addEventListener('click', function () { close(true); });
    });
  }

  // The funnel is a single-page app: the step mounts after page load and can
  // re-render, so mount whenever the step is present and the panel is not.
  mount();
  new MutationObserver(mount).observe(document.body, { childList: true, subtree: true });
}());

Tracking

  • Panel opened: VWO click goal on #av-ad-prep-trigger, counted once per visitor. Variant only.
  • Details step completed: the visitor reaches the photos step (its title “Lisää vielä kuvat” shows). Both arms.
  • Ad submitted: the funnel's existing submit goal. Both arms.

Do not

  • Show it on any other step, on the B2B funnel, or outside the funnel.
  • Open it by default, remember whether it was opened, or store anything.
  • Change the step's title, description or fields.
  • Add classes or styles beyond the snippet's own CSS.
  • Use the photo tips' copy: this panel has its own.

Acceptance criteria

  • Control: the details step is unchanged.
  • Variant: the link sits 24px under the description, under both titles of the step, on desktop and mobile, closed on every visit.
  • The panel matches the photo tips in colour, radius, padding, type and animation.
  • The link reports aria-expanded; ✕ and “Sulje” close the panel and return focus to the link.
  • Going to the next step and back shows exactly one panel, closed.
  • No console errors and no horizontal scroll at 360px.
  • The goals above record in VWO.
